# DevOps2

Projeto desenvolvido para a disciplina de DevOps.

## Descrição

Este projeto tem como objetivo aplicar conceitos de DevOps, integração contínua e automação utilizando GitHub Actions.

## Tecnologias

- Git
- GitHub
- GitHub Actions
- C#

## CI/CD

O projeto utiliza GitHub Actions para executar automaticamente o processo de integração contínua.
